# 定制化秋招求职网站 —— 实施计划

## 一、目标与形态
为你（2027届AI方向博士，研究方向：语义通信 / 神经网络对抗攻击 / 大模型水印）搭建一个**个人专属秋招作战平台**：
- **技术栈**：Vite + Vue 3 + Vue Router + Element Plus（组件库，表格/表单/日历现成好用）
- **部署**：GitHub Pages 免费托管，配 GitHub Actions 自动构建——你以后只要编辑数据文件并 push，网站 1 分钟内自动更新（解决"后续会有很多岗位出来"的诉求）
- **数据分工**：招聘知识库/公司库/时间线 = 仓库内数据文件（可随时更新提交）；个人数据（投递记录、档案、清单勾选）= 浏览器 localStorage + 导出/导入 JSON 备份
- **地域聚焦**：北京、上海、杭州、苏州、南京（不含广深与中部城市），全站内容按此取舍

## 二、站点模块（9 个页面）
1. **总览仪表盘**：关键倒计时（国考笔试/网申截止/选调公告季）、按当前日期自动生成的"阶段行动建议"、三赛道投递统计、临近截止事项高亮
2. **企业赛道**：
   - 研究方向→岗位映射：大模型水印→大模型算法/AIGC安全与内容溯源；对抗攻击→AI安全攻防/红队/模型评测；语义通信→6G/通信算法/无线AI
   - 公司库（可按性质[私企/AI创企/国企院所/外企]、城市、匹配度筛选）：私企大厂、AI创企（DeepSeek/智谱/月之暗面/MiniMax等）、国企研究院（三大运营商研究院、中国星网、电科14/28所[南京]、航天院所、之江实验室[杭州]、**紫金山实验室[南京]——语义通信最强对口**、南瑞[南京]等）、外企（微软亚研/苹果/NVIDIA/高通等）
   - 博士专项人才计划汇总表（天才少年、TopSeed、北斗、AIDU等，现状以检索核实为准）
   - 秋招全流程：提前批/正式批节奏、笔试面试形式、博士定级与薪资对比
3. **公务员赛道（零基础入门）**：工作内容与单位类型、博士对口部门映射（网信办/工信部/数据局/公安网安←你的研究方向）、国考与省考两条路径、报名条件详解（博士年龄放宽、应届身份认定、专业目录匹配坑）、十步全流程（公告→职位表→报名→笔试[行测+申论]→面试→体检→政审→录用）、官方信息渠道汇总
4. **选调赛道（零基础入门）**：选调生是什么/与公务员区别、中央选调vs定向选调vs普通选调对比、报考硬条件（党员/学干/博士年龄放宽至40）、**学校推荐这一关键前置步骤**、**重点省份详解**（北京定向选调+优培、上海定向选调+储备人才、江苏名校优生、浙江选调：时间窗/高校范围/博士待遇定级/笔试面试形式）、公告短窗口强提醒、信息渠道（省委组织部+学校就业网）
5. **投递进度看板**：投递记录 CRUD（单位/岗位/赛道/状态流转[想投→网申→笔试→各轮面试→offer/拒]/截止日/链接/备注），看板+列表双视图，localStorage 存储
6. **秋招日历**：内置2027届关键节点（检索核实），月视图+列表，自定义事件，临近截止全站提醒
7. **面试笔试准备**：算法岗技术面考点清单（LLM/RLHF/对抗攻击/水印/通信基础）、手撕代码题单、三大研究方向的"讲给面试官"叙事模板、行测申论备考规划、选调面谈常见题、外企英文面模板
8. **博士简历与材料指南**：博士一页简历要点、研究方向的安全化表述技巧（对抗攻击→AI安全）、按赛道定制版简历策略、材料清单（就业推荐表/三方/成绩单/党员证明等，按赛道动态勾选）、京沪杭苏宁落户与人才补贴速查
9. **个人档案**：学校/专业/政治面貌/生源省/目标城市，驱动选调资格自查（政治面貌、双一流范围判断）与默认筛选；数据导出/导入/清空

## 五、实施步骤
1. **环境检查**：确认本机 node/npm/git 版本（缺 Node 则在 README 写明安装指引，代码照常完成）
2. **信息检索**：按第三节清单多轮搜索核实
3. **搭建骨架**：Vite+Vue3 脚手架、路由、侧边栏布局、Element Plus 引入
4. **编写数据文件**：三大赛道知识库+公司库+时间线（内容量最大的一步）
5. **实现9个页面与交互**：看板/日历/档案的 localStorage 逻辑
6. **自测**：npm run dev 后用浏览器逐模块点检渲染与交互（含移动端宽度），npm run build 验证构建
7. **部署配置**：deploy.yml + README 部署指南（你创建仓库后 push 即自动上线；若本机 git/gh 可用，我协助完成推送）
8. **交付总结**：使用说明、数据备份方法、日常更新流程

## 六、说明
- 招聘/考公信息时效性强，站内所有时间类数据均带来源与核实日期，你后续可自行编辑 data 文件维护
- 个人数据在浏览器本地，换设备/清缓存前用"导出"按钮备份
